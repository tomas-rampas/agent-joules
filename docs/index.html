Agent Joules

Which agent step burns the most energy?

GPU energy per agent step, measured on your GPUs. Agent Joules wraps each agent of a Microsoft Agent Framework workflow in a metered chat client that records tokens, latency and cost for every model call, and on a GPU you control, joules and watts through NVML.

The live dashboard

To see the page without installing anything, open the hosted replay, which plays the committed cloudgpu and local runs in the browser with no key and no server. Replay without a GPU or key:

dotnet run --project src/AgentJoules.Cli -- dashboard --replay results/20261026T124721Z-cloudgpu.json --speed 4 --exit-after 60

Nemotron and Nebius

How it uses NVIDIA Nemotron

  • local nvidia/Llama-3.1-Nemotron-Nano-4B-v1.1 served by an NVIDIA NIM container on the laptop GPU.
  • cloudgpu nvidia/nemotron-3-nano served by an NVIDIA NIM container on a Nebius AI Cloud VM with one NVIDIA H100 80GB.
  • nvidia nvidia/nemotron-3-nano-omni-30b-a3b-reasoning on the hosted build.nvidia.com endpoint.
  • nebius nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B on the Nebius Token Factory endpoint.

Where Nebius came in

The nebius tier calls Nebius Token Factory, which served nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B for the whole workflow: a hosted comparison tier with no GPU to own or rent, measured for tokens, latency and cost from a laptop with a key alone.

The cloudgpu tier ran on one Nebius AI Cloud GPU VM (preset 1gpu-16vcpu-200gb, region eu-north1) where the NIM container and the NVML meter share one H100; rental 1.509 GPU-hours (estimated) at USD 4.63 per hour (the console price), about USD 7 for the whole rental window (estimated; docs/cloudgpu-run.md), VM deleted after the run.

Judges without a GPU: four actions, no key needed

  1. dotnet test runs the unit tests.
  2. dotnet run --project src/AgentJoules.Cli -- validate results/ checks the committed results files against the schema and prints Validated <n> files.
  3. Open the hosted replay at replay/ (the live dashboard page replaying the committed cloudgpu and local runs in the browser, no key) or docs/report/index.html, the committed report page.
  4. Run the dashboard replay command: 
    dotnet run --project src/AgentJoules.Cli -- dashboard --replay results/20261026T124721Z-cloudgpu.json --speed 4 --exit-after 60

Honesty rules

Five labels, never zero

measured, estimated, model-judged, N/A, not-reported. A missing value is never written as zero.

Generated, not typed

The README results block is generated from the committed results files by report --update-readme.

GPU board only

Energy is GPU-board energy. Judge calls are excluded from workflow totals. Models differ across tiers and are not ranked.
