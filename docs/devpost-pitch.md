# Agent Joules: Devpost elevator pitch

## Devpost elevator pitch (limit 200 characters)

**A (recommended)** (192 characters)

> Which agent step burns the most energy? A .NET middleware meters local GPU joules per Microsoft Agent Framework step and compares cost and latency with NVIDIA Nemotron on Nebius Token Factory.

Why recommended: it packs the most judge-scored signals (middleware, .NET, Microsoft Agent Framework, NVIDIA Nemotron, Nebius Token Factory) behind a question hook, and it keeps energy on the local GPU and the hosted comparison on cost and latency.

**B** (193 characters)

> Your agents report tokens, not energy. Agent Joules meters local GPU joules per .NET Microsoft Agent Framework step, so teams can compare cost and latency with Nemotron on Nebius Token Factory.

**C** (186 characters)

> A power meter for AI agents: a .NET middleware measures GPU energy per Microsoft Agent Framework step, so developers can weigh local NVIDIA Nemotron against Nebius Token Factory on cost.

## Spoken version (30 seconds)

(82 words)

> Your agents report tokens, not energy. So which step burns the most power? Agent Joules shows you. It is a .NET middleware for Microsoft Agent Framework that uses NVIDIA's GPU management library to attribute joules, watts, tokens, latency, cost and a quality score to every agent step on your local GPU. The same workflow runs on NVIDIA Nemotron locally and on Nebius Token Factory, so you can compare cost and latency. Energy appears only where it is measured: on your own GPU.
